# Student_Management_System

## INTRODUCTION

MongoDB is a popular NoSQL database management system that stores data in the form of documents. Unlike traditional relational databases, MongoDB does not require data to be stored in fixed rows and columns. In this project, a Student Management System has been created using MongoDB. The database contains information about 50 students, including their roll number, name, age, marks, and city. Different MongoDB operations have been performed on the student data, such as inserting, displaying, updating, deleting, sorting, counting, and searching records. Comparison operators such as $eq, $gt, $lt, $gte, and $lte have also been demonstrated.

## OBJECTIVES

* To understand the concept of NoSQL databases.

* To learn the basic features of MongoDB.

* To create a database and collection.

* To insert 50 student records.

* To perform CRUD operations.

* To use comparison operators.

* To perform sorting and filtering.

* To understand AND and OR operations.

## Technologies Used

- MongoDB
- MongoDB Compass / MongoDB Shell

## Conclusion

The Student Management System demonstrates the basic concepts and operations of MongoDB using student data.
